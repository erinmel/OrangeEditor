Build with graphs.

OrangeEditor is a Rust foundation for typed node graphs. Build automations in the desktop editor, run them from a terminal, or embed the runtime and editor in your application.

How it works

A graph runs when a trigger fires. Execution wires route actions and data wires carry typed values. Graph-local functions group reusable logic. Installed packages can provide additional nodes while the editor is open.

The project is pre-1.0. The project overview tracks platform qualification and open work.
