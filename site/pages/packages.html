Export a function from the editor

  1. Make a graph function. Right-click its call and choose Export function.
  2. Review the generated ports and dependencies. Set a package ID you own, such as org.example.math, and save the .orangeplug file.
  3. Import it from Packages in the receiving editor. Place the node from the library and select the receiving graph’s own connection where the card exposes one.

For automation, publish the same saved function by name. Use a file that already contains a function called Compute power.

cargo run -p orange-cli --locked -- publish graph.json "Compute power" org.example.math 0.1.0 power power.orangeplug

Pack an authored directory

A package directory starts with manifest.json and the node definitions under nodes/. A graph-backed provider uses a matching graphs/ entry. A Wasm provider carries the component at the execution entry declared in its manifest. Put localized labels in the Fluent files named by the manifest.

The Remember fixture provides a minimal manifest, definition, and graph provider. pack computes the content digest. Pass the output archive when validating or running its consuming graph.

cargo run -p orange-cli --locked -- pack app/crates/apps/orange-cli/packages/remember remember.orangeplug
cargo run -p orange-cli --locked -- check app/crates/apps/orange-cli/graphs/remember-on-trigger.json --package remember.orangeplug
cargo run -p orange-cli --locked -- run app/crates/apps/orange-cli/graphs/remember-on-trigger.json --package remember.orangeplug

Use --store <dir> to retain packages for subsequent CLI commands. Use orange bind on a hand-authored graph that needs saved provider bindings. It updates the file and keeps a .bak copy.

Permissions and updates

Review the archive’s requested capabilities during installation. The host approves grants per package. Graphs pin package and provider identities, and running flows can keep the providers they started with. Install new versions side by side and review bindings before moving a graph.

Ship archives for installed graph and Wasm providers. Native Rust libraries are trusted start-time integrations loaded separately. The expansion contract specifies archive validation, permissions, provider pins, feeds, and hot updates.
