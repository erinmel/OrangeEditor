# Graph and plugin examples

This area will contain small documented workflows and SDK examples that are validated against exact graph/package versions. No executable graph examples have been delivered yet; the current JSON examples remain specifications in [docs/](../README.md).

Examples contain credential references and redacted/mock data. Record expected output/diagnostics, package locks and the verification command with each future executable example. They do not auto-connect to personal services on import. Golden graph-language fixtures are delivered by WU-00 and SDK compatibility vectors by WU-03; their final locations are recorded with those work units.
