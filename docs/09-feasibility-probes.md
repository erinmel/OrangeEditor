# Feasibility probes

Status: **all probes NOT RUN.** These are the minimal experiments that must pass before the matching production work is committed. Record each result in [10](10-tooling-and-sources.md): source versions, exact commands, feature set, OS/hardware, output, pass/fail and any resulting ADR change. The project uses no game engine (ADR-02); the editor UI is egui hosted by eframe, and the core has no UI, window or engine dependency (ADR-01, ADR-21).

| ID | Minimal experiment | Acceptance / architectural consequence |
|---|---|---|
| P-01 | Pin the selected Rust toolchain and the exact `egui`/`eframe` versions; compile the smallest eframe app with an explicit feature set. Use `cargo metadata --locked`, `cargo check --locked` and `cargo tree -e features`. | Exact versions, MSRV and licenses recorded; the core crates stay free of UI, window and renderer dependencies. |
| P-02 | Build a canvas slice: numeric/text/enum settings, a plugin-declared panel, wire drag, 10,000 total nodes with about 500 visible, focus-preserving edits, IME and keyboard navigation, expanded and RTL pseudo locales, CJK shaping and font fallback, plural/fallback, and a language switch during composition; measure a 1,000-visible-node stress case separately. Drive part of it through `egui_kittest`. | Meet the W4 budgets in [06](06-quality-and-validation.md) and NFR-10/16; screen readers reach nodes, ports, errors and logical links. A required capability that fails → compare the ADR-02 fallback before WU-05. |
| P-03 | Run async graph actions through the bounded bridge between the Tokio host runtime and the UI thread, and headless; pause and resume the UI; inject task failure, queue saturation, cancel/stop and a stale generation result. | No lost accepted completion, deterministic graph state under declared ordering, bounded shutdown and no stale write. The UI thread never waits on graph, file or network work. |
| P-04 | Decode and route two simultaneous players to different real/virtual endpoints; remove one; create and remove an app-owned PipeWire virtual source on Linux. | Verify channel/rate mapping, cleanup and failure policy on actual supported OS/backend combinations. Default-sink playback alone fails this probe. |
| P-05 | Run a saved graph with no display or GPU, then the same logic through a host adapter with typed resource handles; delete and recreate the host objects while handles exist. | The core succeeds with no window. The adapter rejects stale handles and reports missing capabilities. |
| P-06 | Build and launch the minimal app on Windows, macOS and Linux; exercise Wayland/X11 where supported, DPI, native dialogs, clipboard and OS secret-store availability. Inventory runtime libraries. | Explicit supported-target matrix, install/runtime prerequisites, reproducible CI builds and real-machine evidence; cross-compilation alone is not execution verification. |

Example existence or a crate's feature list is not proof of platform completeness. Each probe tests real OS sessions.
