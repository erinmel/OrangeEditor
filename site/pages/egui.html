Add the editor to an egui project

Use a matching egui version and pin the host and UI to the same OrangeEditor revision. The editor library draws in your existing egui frame. Your application supplies the window and renderer.

[dependencies]
egui = "=0.37.0"
orange-host = { git = "https://github.com/erinmel/OrangeEditor.git", rev = "@revision@" }
orange-editor-ui = { git = "https://github.com/erinmel/OrangeEditor.git", rev = "@revision@" }

Compose panels in your layout

Keep an Editor, Host, and Events receiver in your application state. Initialize the editor with Editor::new(). Open a draft with editor.open_untitled(&mut host, orange_host::new_document()?) in a fallible initializer.

In the egui frame, ingest flow updates and draw into the UI your application provides. The following is the layout portion of the frame:

editor.poll_events(&events);
editor.ui_with_layout(ui, &mut host, |editor, ui, host| {
    editor.toolbar(ui, host);
    editor.workspace_bar(ui);
    egui::Panel::left("graph-nodes")
        .show(ui, |ui| editor.nodes_panel(ui, host));
    egui::Panel::right("graph-inspector")
        .show(ui, |ui| editor.right_panel(ui, host));
    egui::CentralPanel::default()
        .show(ui, |ui| editor.canvas_panel(ui, host));
});

The editor also provides log_panel. After rendering, consume Editor::take_request and handle the corresponding file action in your app. Integrate a repaint wakeup or a periodic repaint while a flow is running so updates appear even when the user is idle.

Keep the canvas and bring your own app chrome

Start with one Host, one Editor, and the host's event receiver. Open a graph into the editor. Draw your app navigation, then use the editor's layout hook for the canvas and any OrangeEditor panels you choose.

editor.poll_events(&events);
editor.ui_with_layout(ui, &mut host, |editor, ui, host| {
    egui::CentralPanel::default().show(ui, |ui| {
        editor.canvas_panel(ui, host);
    });
});

Omit the stock toolbar, workspace bar, sidebar, and log by leaving out those panel calls. Add right_panel back for the inspector. If you draw your own toolbar, use Editor::ask for host-owned file actions and consume Editor::take_request after the frame. For example, an app can handle FileRequest::Open by reading a document from its own store and passing the JSON to Editor::open.

The runnable example uses a branded header, optional inspector, and app-owned New, Open, and Save As actions. From the repository root:

cargo run --locked -p orange-desktop --example embed_editor

Pass a path to a .ttf or .otf file after -- to try a custom typeface. Complete example source

Colors, spacing, and style

Set the application’s egui style before the first frame. The editor uses the context for panel colors, widget states, selection, spacing and typography. Calling orange_editor_ui::apply_theme installs the default desktop styles. Apply it first if you want to start from those styles.

let theme = egui::Theme::Dark;
ctx.set_theme(theme);
let mut style = (*ctx.style_of(theme)).clone();
style.visuals.panel_fill = egui::Color32::from_rgb(20, 31, 45);
style.visuals.extreme_bg_color = egui::Color32::from_rgb(13, 22, 33);
style.visuals.selection.bg_fill = egui::Color32::from_rgb(32, 102, 110);
style.spacing.item_spacing = egui::vec2(8.0, 6.0);
ctx.set_style_of(theme, style);

Configure both egui::Theme::Light and egui::Theme::Dark when your app supports both. For shared controls that accept a token set, use UiTokens::for_surface to adapt to your app’s visuals. For an explicit shared palette, use UiTokens::install with ThemeMode::Custom and your density. See Controls reference and Theme fields.

Fonts and value formatting

Install font data once with ctx.set_fonts. Insert your font at the front of a family and retain the defaults as fallbacks. Use Style::text_styles for roles such as body, heading and monospace. Provide glyph coverage for the languages your app offers.

let mut fonts = egui::FontDefinitions::default();
fonts.font_data.insert(
    "brand".into(),
    std::sync::Arc::new(egui::FontData::from_owned(font_bytes)),
);
if let Some(family) = fonts.families.get_mut(&egui::FontFamily::Proportional) {
    family.insert(0, "brand".into());
}
ctx.set_fonts(fonts);

Format values in your own panels with ordinary Rust formatting, for example format!("{level:.1} dB"). Retain the numeric value in state. Node authors can specify control hints through orange_sdk::Control for fields that need a unit, decimal precision or a specific widget. Use the host's typed authoring methods to make graph edits. Control hints API

let definition = definition.input_control(
    "threshold",
    orange_sdk::Control::slider().range(-60.0, 0.0).unit("dB").precision(1),
);

Use this hint on a numeric input named threshold. The node definition still specifies the actual type and valid values.

Icons and labels

Register icons::set_command_painter on the context. Draw the supplied command inside the supplied rectangle using the current foreground color. Return false to let OrangeEditor draw its default icon for that command.

icons::set_command_painter(ctx, Some(std::sync::Arc::new(
    |painter, rect, icon, color| {
        if icon != icons::PROPERTIES {
            return false;
        }
        let radius = rect.width().min(rect.height()) * 0.25;
        painter.circle_stroke(rect.center(), radius, (1.5, color));
        true
    },
)));

Use i18n::add_application_catalogs before the first editor frame to override labels. Use Editor::set_language to select the locale. Keep file extensions, graph IDs, port IDs, and stored values independent of translated labels.
