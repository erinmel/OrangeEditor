Wasm guest interface

The guest interface is orange:expansion@1.1.0. Use the plugin world for the guest exports and host imports. Guest calls exchange typed values. Composite values use the checked orange.value.v1 literal representation. settings.get supplies saved node configuration and optional capabilities are linked according to the package’s grants.

The probe implementation exercises those bindings. For the separate native tier, the native example demonstrates export_plugin!. Native libraries run with the host process’s authority and must be built against the same compiler and lockfile.

Versioned contracts

  • Graph language — types, scheduling, node kinds, functions and extension rules.
  • Graph file format — document JSON, typed values, signatures and locks.
  • Expansion packages — manifests, permissions, providers and lifecycle.
  • Internationalization — Fluent catalogues, namespaced text, arguments and locale fallbacks.
  • Embedding contract — the supported application boundary and source compatibility.
