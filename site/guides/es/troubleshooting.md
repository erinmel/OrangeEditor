# Solución de problemas

## El grafo no arranca

Abre **Problemas** y sigue el primer diagnóstico hasta la tarjeta, el puerto o el paquete. Es posible que falte una conexión o un tipo. Revisa [tipos y conversiones](../types-and-conversions/).

## Arranca pero no pasa nada

Dispara la entrada manual u ocasiona el evento que el disparador espera. Comprueba que la salida de ejecución esté conectada. Puedes comparar con [el contador](../count-button-presses/).

## El nodo indica que falta un proveedor

Abre **Paquetes** y revisa el identificador, la versión y el proveedor que exige el grafo. Instala ese paquete o desvincula y vuelve a vincular el proveedor de forma deliberada si el editor ofrece esa opción. Consulta [cómo actualizar paquetes](../packages/).

## Falló una conexión

Revisa la configuración y la autorización de la conexión. Distingue un código de error HTTP de un fallo de red con la [guía de HTTP](../call-an-http-api/).
