Open the editor

Check the releases for builds available for your platform. To run from source, clone the repository, install rustup, and run the command below from the repository root. The checkout selects Rust 1.99.1 through rust-toolchain.toml. Linux source builds require ALSA development headers.

cargo run -p orange-desktop --locked -- app/crates/apps/orange-cli/graphs/set-on-trigger.json

Run your first graph

  1. Find the manual trigger and the Set Variable card. The execution wire runs from the trigger to the action.
  2. Press Run, then Fire on the trigger. Open Variables and look for total, which becomes 7.
  3. Stop the graph. Change the action’s value from 7 to 9, run again, and fire the trigger. Confirm total now becomes 9.
  4. Use Save as to keep your own copy of the experiment.

Check and run from the terminal

cargo run -p orange-cli --locked -- check app/crates/apps/orange-cli/graphs/set-on-trigger.json
cargo run -p orange-cli --locked -- run app/crates/apps/orange-cli/graphs/set-on-trigger.json --watch

At the runner prompt, enter trigger 1 to fire the only manual trigger. Enter quit to stop. check validates a document and preview computes eligible pure outputs without starting a flow.

Example graphs

  • Counter with reset — increment, decrement, and reset a run variable.
  • JSON extraction — extract and convert fields offline.
  • HTTP with failure handling — route successful responses, HTTP error statuses, and transport errors. Its default endpoint requires a local server.
  • Quiet mic gate — follow an audio signal through a gate and meter. Choose devices when ready to listen.
