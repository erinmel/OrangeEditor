Place and wire nodes

  1. Open Nodes and search by node label or task. Use Conversions for type conversions. Selecting a result lets you place it on the canvas.
  2. Connect matching ports. Execution wires schedule actions. Data wires feed typed inputs. For a mismatch, place an explicit conversion. Dropping a wire on empty canvas opens suggestions for the port.
  3. Select a card to see its Properties. Edit defaults, choose declaration references, and configure settings or dynamic ports there.
  4. Review Problems, press Run, and fire a trigger. Inspect variables, wires, or the log to see what happened.

Select one built-in OrangeEditor node and press F1 to open its reference page. The Branch reference, for example, shows the card, what each port does, and a graph you can run.

Use the language picker in Settings to switch between English, Spanish, and the Japanese preview. Node search can still match terms from other supported languages.

Variables, events, and bridges

  • Variables hold state. Declare a typed variable, then select it on a read or write node. Use a run variable for a counter shared by activations.
  • Dispatch and Listen share a channel. In Properties create a pulse for a trigger alone, or choose a typed payload. Each Listen on the channel starts a flow activation. Use Await Event to continue an existing activation when an event arrives or its timeout expires.
  • Bridge Out and Bridge In share a value on demand. Place a Bridge Out, connect its input, and choose + Add Subscriber to place a matching Bridge In. The subscriber supplies a value without starting execution.

Connections and failure routes

Create a connection in Connections, then select it on the relevant node. Use the application's credential controls so the graph stores a reference to the OS secret store. Authorize the graph to use the connection when prompted.

For an HTTP request, handle response status separately from a failed request. When a node exposes Failed and Error, route the execution through Failed before consuming that Error value. Handle Cancelled where the node exposes it and cancellation needs cleanup.

Troubleshoot a graph

Run is blocked
Open Problems and follow the first diagnostic to the affected card, port, or package.
Nothing runs after start
Fire a manual trigger or cause the event that the entry expects. Then check its execution outputs.
A saved node has a missing provider
Review the graph’s required package, version, and provider in Packages. Install the exact package or use a deliberate provider rebind where the editor offers it.
